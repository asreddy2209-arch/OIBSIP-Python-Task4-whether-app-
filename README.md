# 🌤️ Weather App

## 🚀 Project Overview

This project is a **Weather Application** developed using Python.

The application retrieves weather information for a specified location using a weather API and displays the available weather details to the user.

The project demonstrates API integration, HTTP requests, JSON data processing, user input handling, and error handling.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Accept a city name from the user.
* Connect to a weather API.
* Retrieve current weather information.
* Process API response data.
* Display temperature information.
* Display weather conditions.
* Handle invalid city names.
* Handle API errors.
* Provide a simple weather information system.

## 🔑 API Configuration

The application requires a valid API key from the selected weather service.

The API key should be stored securely and should not be uploaded publicly to GitHub.

Example:

```python
API_KEY = "YOUR_API_KEY"
```

Replace `YOUR_API_KEY` with your own API key.

Check Python installation:

```bash

```

### Step 2: Install Dependencies

```bash

```


Enter the name of the city to retrieve its weather information.
